boost

Operating environment requirements
please use 
nodejs v20+
pnpm v9+
vercel v35+

Install dependencies
```shell
pnpm install
```

install vercel cli
```shell
npm i -g vercel
```

get env(OR use .env.local)
```shell
vercel env --pull
```

start dev command
```shell
vercel dev
```

deploy command
```shell
vercel --prod
```
